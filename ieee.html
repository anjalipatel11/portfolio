01

Project Overview

Mentor Link is an internal AI-powered application developed for IEEE's EMBS Society to simplify mentor and mentee matching.

The platform combines user profile information, AI-generated recommendations, and an intelligent chatbot to help users discover compatible mentorship opportunities through a streamlined digital experience.

05

AWS Architecture

This architecture supports an in-depth depiction of the application's processes through the backend. It passes through various technologies and services that trigger a chain of events to follow and eventually provide the user with a result.

System Architecture Mentor Link

IEEE employees authenticate through the web application, their requests are handled by a Spring Boot backend, which retrieves relevant company information from DynamoDB, S3, and a knowledge base using OpenSearch. A Lambda function then sends the most relevant context to Azure OpenAI to generate an accurate response, which is returned to the user.
